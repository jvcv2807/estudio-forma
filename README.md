## ✨ Recursos & Funcionalidades

1. **Galeria de Projetos com Filtro Dinâmico:**
   - Categorias: *Residencial*, *Comercial* e *Consultoria Express*.
   - Filtragem instantânea sem reload via JavaScript puro.
2. **Modal Interativo de Ficha Técnica:**
   - Visualização ampliada, metragem, localização, ano de entrega e memorial de conceito com animação fluida e backdrop-filter blur.
3. **Simulador de Prazo & Escopo:**
   - Cálculo automático do tempo estimado de projeto conforme tipo de imóvel, metragem (m²) e quantidade de cômodos.
4. **Tema Claro / Escuro (Dark Mode):**
   - Paleta de cores sofisticada inspirada em linho, terracota e concreto, com persistência no `localStorage`.
5. **Formulário de Contato & Briefing:**
   - Coleta de dados com feedback visual imediato.
6. **Mobile-First & Acessibilidade:**
   - Menus responsivos, contraste em conformidade com WCAG AA e navegação acessível por teclado.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Marcação estruturada e acessível (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3 Moderno:** CSS Grid, Flexbox, Custom Properties (`:root` e `[data-theme="dark"]`), animações e tipografia editorial com Google Fonts (*Cormorant Garamond* e *Plus Jakarta Sans*).
- **JavaScript ES6+:** Manipulação limpa do DOM sem dependências ou frameworks pesados.

## 🚀 Como Executar Localmente

Basta clonar o projeto e abrir o `index.html` em qualquer navegador:

```bash
git clone https://github.com/jvcv2807/estudio-forma.git
cd estudio-forma
xdg-open index.html # ou no Windows: start index.html
```
